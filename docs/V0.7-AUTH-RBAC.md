# SDI One v0.7 — Authentication & RBAC

This milestone adds the first real security layer to SDI One.

## Included

- Real login page
- Session cookie
- Logout action
- Protected dashboard/report/search routes
- Seeded system admin user
- Role definitions
- Permission definitions
- Company access model
- Job access model
- Security dashboard
- Users, roles, permissions and access admin pages

## Commands

```powershell
npm install
copy .env.example .env
docker compose up -d
npx prisma@5.22.0 generate
npx prisma@5.22.0 migrate dev --name auth_rbac_v07
npm run seed:all-platform
npm run import:all
npm run dev
```

## Notes

This is local/database authentication. Azure/Entra ID SSO can be added later without replacing the RBAC model.
