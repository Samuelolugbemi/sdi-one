# SDI One v1.4 — Fleet, Ford Pro, Fuel & Telematics

Adds fleet intelligence as a first-class operating domain.

## Capabilities

- Fleet vehicle registry
- Mileage, fuel cost, MPG, maintenance, utilization and location-ready fields
- Ford Pro connector scaffold
- Fuel system connector scaffold
- Geotab/telematics connector scaffold
- Fleet dashboards and vehicle/fuel/maintenance/telematics pages
- Seeded demo operational data for UI validation before production credentials

## Production integration notes

The connector workspaces are credential-ready. Production rollout requires API credentials, approved export files, or database access for each system.
