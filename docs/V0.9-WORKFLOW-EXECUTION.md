# SDI One v0.9 — Workflow Execution Engine

v0.9 converts the workflow foundation into an executable platform service.

## Added

- Workflow step templates
- Workflow action templates
- Workflow executions
- Workflow execution steps
- Workflow action runs
- Workflow event subscriptions
- Workflow queue items
- Workflow runtime helpers
- Demo invoice approval execution
- Workflow execution dashboard
- Workflow run detail page
- Task engine page
- Scheduler page
- Event bus page
- API endpoint for starting workflow executions


## Commands

```powershell
npx prisma@5.22.0 migrate dev --name workflow_execution_v09
npm run seed:v09
npm run import:all
npm run dev
```

## Purpose

This milestone makes SDI One an active platform. Workflows are no longer only designs; they can now create executable runs, move through steps, run actions, generate notifications, write timeline events, and appear in the event bus.
