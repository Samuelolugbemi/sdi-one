# SDI One v1.2 — Salesforce Connector

v1.2 adds the Salesforce connector workbench while preserving SDI's existing Data Loader automation path.

## Scope

- Salesforce connector metadata
- OAuth / External Client App readiness
- Object catalog
- Field mappings
- Sync plan
- Runs and logs
- Local smoke test endpoint
- API readiness endpoints

## Key Pages

- `/dashboard/integration-platform/connectors/salesforce/configure`
- `/dashboard/integration-platform/connectors/salesforce/oauth`
- `/dashboard/integration-platform/connectors/salesforce/objects`
- `/dashboard/integration-platform/connectors/salesforce/mappings`
- `/dashboard/integration-platform/connectors/salesforce/sync`
- `/dashboard/integration-platform/connectors/salesforce/logs`

## API Endpoints

- `/api/integrations/salesforce/health`
- `/api/integrations/salesforce/sync-plan`
- `/api/integrations/salesforce/test-connection`

## Data Loader Continuity

The connector does not break existing Data Loader scripts. It catalogs the same integration surface so SDI One can gradually replace manual/scheduled Data Loader jobs with API-managed sync after OAuth is approved.

## Next Steps

1. Add Salesforce credentials to `.env`.
2. Run `npm run salesforce:test`.
3. Validate object permissions.
4. Compare API output to current Data Loader exports.
5. Enable staged sync by object.
