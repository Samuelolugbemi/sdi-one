# SDI One v0.6 — Milestones 6, 7 and 8

This release adds the next enterprise platform layer on top of v0.5.

## Milestone 6 — Enterprise Automation Platform
- Automation rule models
- Scheduled job definitions and run tracking
- Approval policies
- Task queue foundation
- Workflow designer UI
- Business rules UI

## Milestone 7 — AI & Intelligence Platform
- AI provider configuration
- Prompt template registry
- Executive briefing framework
- Recommendations framework
- Natural language query log model
- AI Copilot UI

## Milestone 8 — Enterprise Integration Platform
- Connector registry
- Integration mappings
- Integration run monitoring
- Integration logs
- Retry policies
- Connector detail workspaces

## Important
External credentials are not included. Sage, Salesforce, POR, Geotab, Ford Pro, Fuel, and Monday connectors are architected and ready for credentials/API implementation.
